          Export to Garmin Connect

          After each run
          Save file puts the run in your Downloads as a TCX file automatically. Share opens Android’s share menu so you can send it to another app; if Android won’t share that file type, it’s saved instead.

          To add the run to Garmin Connect, upload the file on Garmin Connect’s Import Data page. If Garmin Connect is linked to Health Connect on your phone, Garmin can pass your data on from there.
